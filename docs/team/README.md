# team/: one notes file per lane

Each lane of [TEAM.md](../TEAM.md) keeps its own file here and edits only
that one. Sections, newest entry first, each dated (YYYY-MM-DD):

- **Now**: current work, branch, pull request.
- **Decided**: what other lanes must respect, and why.
- **For other lanes**: requests and heads-ups, each starting with the lane
  it is for.
- **Open**: questions waiting on Ely.

| File | Lane |
|---|---|
| [app.md](app.md) | the console, launchers, Windows, CI, docs |
| [submission.md](submission.md) | the weekly FluSight run and the hub |
| [engine.md](engine.md) | the PyBNF fork and the Liu–West filter |
| [model.md](model.md) | Oracle SIHRS and Groundhog methods, replays, scores |
