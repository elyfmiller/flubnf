Forecast the flu season, mechanistically.

FluBNF produces weekly probabilistic forecasts of influenza hospital admissions for all 52 US jurisdictions, packaged in the CDC FluSight submission format together with a shareable weekly report. At its core is a mechanistic transmission model, fitted to each week's data and blended with an empirical companion. Runs, blending, scoring, and packaging are managed from this console.

How it works

One console run each week: the same data pull feeds two independent members, their quantiles blend with equal weights frozen before the season, and the result is packaged for CDC FluSight; the full method is documented under Methods.

PyBNF

PyBNF is Los Alamos National Laboratory's parameter fitting and uncertainty quantification suite for rule-based models. FluBNF runs a fork that adds a sequential particle filter (fit_type=pf), which reweights about 10,000 candidate epidemics per state each week as new admissions data arrive. It supplies the fitting machinery behind the mechanistic member.

bngsim

bngsim is an embeddable, in-process simulation engine for BioNetGen reaction networks. Running simulations inside the fitting process removes the per-simulation overhead of launching BNG2.pl, so a full state-season particle filter pass completes in seconds. Every candidate epidemic the filter weighs is simulated by bngsim.

Installed: {{ versions.bngsim }} · github.com/lanl/bngsim

BNGL and BioNetGen

BNGL is the BioNetGen model specification language, in which the SIHRS transmission model is written. BioNetGen's BNG2.pl performs the one-time network generation that turns the rule-based definition into the reaction network the engine simulates. Keeping the model in BNGL makes its structure explicit, portable, and independently checkable.

Installed BioNetGen: {{ versions.bionetgen }} · bionetgen.org
