Forecast the flu season, mechanistically.

FluBNF produces weekly probabilistic forecasts of influenza hospital admissions for all 52 US jurisdictions, in the CDC FluSight submission format and with a shareable weekly report. A mechanistic transmission model is fitted to each week's data and blended with an empirical companion.

PyBNF

Los Alamos National Laboratory's parameter-fitting and uncertainty-quantification suite for rule-based models, and the fitting framework behind the mechanistic member. FluBNF runs a fork that adds the sequential particle filter (fit_type=pf).

github.com/lanl/PyBNF

bngsim

An embeddable, in-process simulation engine for BioNetGen reaction networks, and the engine the particle filter runs on. It integrates the model's ODEs inside the fitting process, with no per-simulation BNG2.pl subprocess, so each candidate epidemic simulates in seconds rather than minutes.

github.com/lanl/bngsim

BNGL and BioNetGen

The BioNetGen model specification language, in which the SIHRS transmission model is written. At run preparation BNG2.pl expands the rule-based definition into a reaction network, once per state cell, which bngsim then integrates throughout the fit. Keeping the model in BNGL makes its structure explicit and independently checkable.

bionetgen.org
