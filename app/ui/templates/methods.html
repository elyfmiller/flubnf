The SIHRS compartment model

{%- call tips.toggletip("mt-sihrs", "the SIHRS compartment model") %} The SIHRS compartment model, written in BNGL: people move from Susceptible to Infected; most recover directly, a small severe fraction is Hospitalized first, and Recovered immunity wanes back to susceptible. {%- endcall %} Model tab: Oracle SIHRS
{{ dg.sihrs(uid='mm') }} {# the rates sentence as the diagram's key: each symbol and what it is #} {{ tips.heading("Rates", "mt-rates", level=3, cls="mt-h3") }}
β(t)
transmission, a smooth annual harmonic
γ
infections resolve (from the measured generation time)
ρ
the fixed fraction hospitalized
γₕ
discharge
ω
immunity wanes
{{ dg.eq_pf() }}
{% call tips.fold("Why this structure", id="mt-why-sihrs", cls="mt-fold") %}

H is explicit because admissions are the target (the model fits the I to H flux with a fitted ascertainment), waning immunity allows repeat seasonal waves, and seasonal transmission lets each state's data place its peak. Five parameters are fitted per state; ρ, γH and ω are working assumptions, recorded as such in flubnf/sihrs_priors.py.

{% endcall %}

Fitting: a sequential particle filter

{%- call tips.toggletip("mt-fit", "the filter's engine", title="The engine") %} A particle filter (fit_type=pf in a fork of PyBNF). BNG2.pl expands the BNGL model into a reaction network once per state when a run is prepared; the filter then integrates it in process with bngsim, so a state-season fit takes seconds. {%- endcall %}

The Oracle step: past seasons' growth, blended in

Model tab: Oracle SIHRS
{{ dg.oracle_pipeline(uid='mp') }} {% call tips.stats("mt-facts", label="The step") %} {{ tips.stat("Sample paths", "30,000", "per state", "At three replicates; each gets its own donor.", id="mt-paths") }} {{ tips.stat("Donors", "1", "per sample path", "One donor per sample, not per forecast, keeps both the filter's uncertainty and the donors' spread.", id="mt-donor") }} {{ tips.stat("Donor window", "2", "epiweeks", "An earlier season's growth path within two epiweeks of the forecast week, any jurisdiction.", id="mt-window") }} {{ tips.stat("Growth blend", "half and half", "", "The geometric mean of the filter's growth and the donor's.", id="mt-blend") }} {% endcall %} {{ dg.eq_oracle() }}
{% call tips.fold("What it does", id="mt-oracle-what", cls="mt-fold") %}

Each of the filter's forecast sample paths (30,000 per state at three replicates) gets one donor: a growth path from an earlier season within two epiweeks of the forecast week, any jurisdiction, the calendar-donor principle the Groundhog uses. Its growth over each forecast week becomes the geometric mean, half and half, of the filter's and the donor's, propagated in closed form from the filter's own state. One donor per sample, not per forecast, keeps both the filter's uncertainty and the donors' spread.

{% endcall %} {% call tips.fold("Donor pool", id="mt-oracle-donors", cls="mt-fold") %}

{{ oracle_text.BANK_TEXT.pool }}

{% endcall %} {% call tips.fold("Why blend in past seasons", id="mt-oracle-why", cls="mt-fold") %}

A filter carries today's growth forward, which is right while a season keeps its course and wrong at the turns; past seasons at the same calendar week show how seasons usually move on.

{% endcall %} {% call tips.fold("How it relates to the Groundhog", id="mt-oracle-gh", cls="mt-fold") %}

The Groundhog applies donor growth ratios to the last observed count, with no mechanism; the Oracle SIHRS applies donor growth to the fitted state, at half weight. The two are submitted as separate models.

{% endcall %}

Research: the two-strain variant

{{- status("neutral", "not a shipped model") }} Model page: two-strain SIHRS
{{ dg.sihrs2(uid='m2') }} {{ dg.eq_pf2s() }}
{% call tips.fold("What it does", id="mt-2s-what", cls="mt-fold") %}

Influenza A and B as independent SIHRS circuits, each with its own seasonal transmission and its own susceptible, hospitalized and recovered pools; observed admissions are the ascertained sum, so an early A wave can be followed by a late B wave.

{% endcall %} {% call tips.fold("A second observation channel", id="mt-2s-channel", cls="mt-fold") %}

Besides NHSN admissions, each candidate is weighed by NREVSS typed positives (binomial counts of influenza A among typed specimens), which also set the season-start A/B mix; both channels are vintage data.

{% endcall %} {% set verdict %}{{ status("ok", "stronger at turning points") }} {{ status("error", "worse on the full grid") }}{% endset %} {% call tips.fold("Why it does not ship", id="mt-2s-why", cls="mt-fold", after=verdict) %}

Stronger at turning points but worse on the full grid in the August 2026 evaluation; it stays a research run (the two-strain model page is reachable by URL).

{% endcall %}

The Groundhog

Model tab: Groundhog
{{ dg.analogue_ratios(uid='ma') }} {% call tips.stats("mt-facts", label="The donors") %} {{ tips.stat("Donor window", "2", "MMWR epiweeks", "Donor weeks from strictly earlier seasons, any state, within two MMWR epiweeks of the forecast date.", id="mt-gh-window") }} {{ tips.stat("Minimum", "30", "donors", "Fewer than 30 donors means no forecast.", id="mt-gh-min") }} {{ tips.stat("Donors per state", "about 5", "a season", "States are pooled because one state gives about five donors per season.", id="mt-gh-pool") }} {{ tips.stat("US row", "about 2%", "of donors", id="mt-gh-us") }} {{ tips.stat("Excluded season", "2021-22", "", "2021-22 is excluded from the donors: it peaked in April 2022 and the archive starts 2022-02-05, so it survives only as its growth phase and a calendar-matched pool would read March as still growing. {% call tips.fold("How it forecasts", id="mt-gh-how", cls="mt-fold") %}

A purely empirical model. For horizon h it pools donor weeks from strictly earlier seasons, any state, within two MMWR epiweeks of the forecast date, and scales the last observed value by the empirical quantiles of their h-week growth ratios; fewer than 30 donors means no forecast. States are pooled because one state gives about five donors per season; the US row is about 2 percent of donors, epiweek 53 sits between 52 and 1, and future values are read by date, never by week label.

{% endcall %} {% call tips.fold("The auxiliary donor bank", id="mt-gh-bank", cls="mt-fold") %}

A second pool built the same way on FluSurv-NET hospitalization rates, a committed, digest-checked file; its ratios are shrunk to the admissions scale (fitted on earlier seasons only) and averaged in at a fixed equal weight. This bank is what separates the Groundhog from the bare calendar analogue; it was pre-registered and chosen over an ILI+ bank.

{% endcall %}

Data and verification policies

{{ tips.heading("Every run", "mt-every", level=3, cls="mt-h3") }}
  • uses the data exactly as archived on its forecast date
  • is seeded and reproducible from its ledger entry
  • never imputes a missing week

{% call tips.fold("A newest week that reads 0, collapses, or was not reported", id="mt-newest", cls="mt-fold") %}

A newest week that reads 0, collapses, or was not reported is the forecaster's decision, per state, made in Data issues on the Forecast tab and recorded with the run: what the Groundhog forecasts from when the week reads 0 (abstain, level, extend or blend), or setting the newest one or two weeks aside for both models, or leaving the state out. Such a choice never marks a run modified (docs/MISSING-DATA.md).
