{# "How the Sandbox works": the path from nothing to a fitted model, one line a step, shared by the gallery (a card, open while there are no models) and the workbench (a menu beside Manage). #}
  1. Start a model. Copy the template for a new pathogen, or the example closest to yours; each one fits as shipped.
  2. Edit its three files. model.bngl is the model (a parameter whose name ends in __FREE is fitted), data.exp the weekly counts, priors.conf the range each fitted value is drawn from.
  3. Check. Reads the files without fitting: what would stop a run, and the model's counts at its written values beside the data.
  4. Save and run. The full fit (10,000 particles) gives the estimates; a quick check (200) only shows that the model runs.
  5. Read the result. The first line says whether the fit is sound, the band should cover the data points, and the table gives each fitted value with its 5 to 95% range.
  6. Try a change. Edit and run again, or Duplicate the model under Manage; Compare with sets two runs side by side and lists what changed. Download run holds the numbers as CSV.

Your own counts go in through the data.exp tab: Load data takes the FluSight hub, a dataset or a CSV, and Simulate data draws counts from the model itself to test the fit on values you know.
